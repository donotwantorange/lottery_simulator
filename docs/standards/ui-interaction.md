# 界面与交互规范

整理日期：2026-10-08。适用于网页表单、列表、详情、任务、图表及后续扩展。

本文件集中维护已确认的显示规则；它是开发与验收要求，不表示当前界面已全部实现。具体机制参数属于业务设计，不能靠修改显示规范改变算法。

范围：页面显示与交互的主要维护位置。谁有权限以及资源归属见[权限规范](permissions.md)；数据精度、快照及任务状态的业务含义见[架构与数据规范](architecture-data.md)。本文件规定这些要求如何呈现给用户，不另定义授权或计算语义。

## 1. 全网页共用的显示规则

| 状态 | 展示与操作 | 数据处理 |
| --- | --- | --- |
| 功能关闭 | 保留开关、一句用途和“未启用”；收起参数及带具体数值的生效说明 | 保留合法配置值，运行不使用它们 |
| 功能开启 | 展开适用字段、单位及当前生效说明 | 新功能从合法默认值开始；已填写值恢复 |
| 当前模式不适用 | 隐藏无关字段，不以灰色表单占位 | 不自动转换、清空历史初始状态；有冲突时进入待处理区 |
| 自动计算 | 展示只读数值及简短计算依据 | 由当前规则与参数计算，不提供输入框 |
| 只读或无编辑权限 | 展示详情文本、状态和摘要；只提供当前有权执行的复制/导出等操作 | 后端继续检查权限，隐藏操作不代替授权校验 |
| 已引用规则的结构锁定 | 顺序显示为只读列表并解释“复制后可调整”；合法可修改参数仍可编辑 | 保留现有引用及结构保护 |
| 正在读取或提交 | 显示具体动作；只暂时禁用相关操作，保留已有草稿 | 防止重复提交，不自动重发写请求 |
| 字段无效 | 字段旁说明原因及修正方式；页首汇总并可定位 | 阻止无效请求；错误不能因控件卸载而丢失 |
| 隐藏部分有无效旧数据 | 显示“有待处理设置”及明确修正/放弃入口 | 不悄悄清除，也不让不可见错误锁住保存 |
| 读取失败或无数据 | 分别显示错误＋重试、无记录说明；不再显示加载中 | 失败不能当作空列表或资源不存在 |

“关闭”和“只读”不是同一种状态。编辑页关闭机制时收起输入；详情页展示“已关闭”，需要查看保留参数时使用次级折叠区。操作因加载而禁用可显示等待样式；因权限、错误或缺少前置选择而不可用，应显示对应原因，不统一使用等待光标。

状态同时出现时，按以下顺序决定展示，不能由每个组件各自选取：

1. 先确认登录、资源访问权限及当前资源身份。无权查看时不显示该资源详情；只有查看权时进入只读模式。会话失效后清除私有页面内容，不能以保留草稿为由继续显示前一账号数据。
2. 确认当前模式、父机制及依赖是否适用。父机制关闭时收起全部子参数；父机制重新开启只恢复子机制自己的原开关，不自动把所有子机制开启。互斥项或缺少前置条件时说明原因，不静默替用户选择。
3. 再决定字段是可编辑、只读、自动计算还是收起，最后叠加加载或提交状态。提交中临时禁用不能改变原本的可见性和草稿内容。
4. 无效输入和不适用旧数据作为独立的待处理提示保留，不能被收起覆盖；只读用户看到问题和复制/联系维护者等可用入口，不要求其修改无权编辑的资源。

例如“启用＋只有查看权”显示生效参数的只读详情；“关闭＋有未完成输入”显示关闭摘要及待处理入口；“父关闭＋子开启”收起子参数并说明子设置保留、当前不生效。

## 2. 草稿保留、校验与隐藏字段

1. 数字输入的原始文本、解析后的合法值、字段错误分开保存。状态由上层草稿持有，按稳定资源/角色/稀有度ID和字段名定位，不能仅存在于会随收起而卸载的输入组件内。清空、小数输入过程和失焦不得自动变成0或丢失文本。
2. 关闭机制仅切换启用状态。合法参数继续保存在现有配置字段中；关闭后保存、重新打开页面并再次启用，应恢复这些值。无效原始文本只是本次页面草稿，不持久化到数据库，也不新增浏览器长期缓存。
3. 关闭前存在无效输入时，主体仍收起，但开关下显示“有未完成的参数修改”，可“展开修正”或“放弃未完成输入，恢复上次合法值”。放弃需明确点击，不能静默将旧值作为新值提交。处理完成前保留可见原因并阻止保存。
4. 保留后端现有格式、类型与存储约束：关闭功能不表示任意非法数字可以存入配置。已关闭机制的合法保留值不因运行语义而阻止保存；若服务端指出其中有无效数据，自动定位待处理区。不得仅删除前端校验来绕过后端，也不得一律填0替代隐藏值。
5. 规则或模式切换留下的实验初始状态，独立于机制配置草稿处理：列出旧值、当前不适用原因，用户明确修正或清除后再提交。已关闭小保底的合法0计数不显示为错误；已不存在稀有度ID及非零冲突按服务端约束处理。
6. 删除角色或稀有度时清理对应值和错误引用，其他字段错误不受影响，与角色数据删除同步处理。再次启用首次赠送时按稳定ID核对主池档位；若结构变化需要调整，展示差异并确认，不凭控件展开自动删除保留数据。

## 3. 操作模式、草稿生命周期和版本冲突

| 模式 | 页面标识与主要操作 | 写入时点 |
| --- | --- | --- |
| 新建 | “新建规则/角色池/配置”；填写后“保存新建…” | 保存成功才创建对象 |
| 编辑 | 标明正在编辑的对象；“保存修改” | 显式保存并通过修订检查后更新 |
| 查看 | 只读详情；按权限提供“编辑”“准备副本”“导出” | 查看不写入 |
| 复制 | “准备某对象的副本”；标明来源、名称、类型及需要的规则映射 | “保存副本”才调用复制接口创建新ID；取消不留下对象 |

复制准备阶段使用现有复制接口支持的名称、类型及池映射字段，不隐式保存源对象未保存的修改。来源为已保存版本时明确写明；用户取消或改名不会提前创建数据库对象。保存副本后可继续编辑新对象，保留最初作者署名及服务端权限校验，不修改原资源。

- “有未保存修改”依据可保存值变化及未完成输入判断，普通展开、筛选和分页不算业务修改。切换编辑对象、新建另一对象、载入/导入配置或站内离开将丢失草稿时，提供“继续编辑／放弃修改”；不在普通开关或折叠操作时重复确认。
- 网络失败、校验失败和读取列表失败保留当前草稿；保存成功才将服务端返回值设为已保存基准。重新加载最新版本会覆盖草稿时必须说明；浏览器关闭/刷新使用可用的原生未保存提示，不承诺跨崩溃恢复或新增自动保存系统。
- 版本冲突保留本页草稿，显示“该对象已在别处修改”；重新加载前确认放弃本页修改。不自动覆盖远端、不偷偷修改修订号后重试，也不新增自动合并编辑器。关联规则/池变化时，对相关预览和初始确认重新校验。
- 权限被撤销后停止写入、复查访问权；仍有查看权则退回只读，无查看权则清除资源详情。账号切换不复用上一账号的草稿。
- 需要确认的动作限定为删除、丢弃实际修改、清空已有名单/映射数据、改变初始状态含义等有实际后果的决定。普通筛选、展开、收起和无修改的导航不增加确认弹窗。预览后的“确认并开始模拟”本身就是确认，不再套一层相同弹窗。

## 4. 异步请求、加载及提交结果

- 规则、池、历史、图表和导入预览都以“当前账号＋资源/查询条件”绑定读取结果。快速从A切换到B时取消A请求或忽略其返回，A即使晚返回也不能覆盖B；使用现有请求取消和会话代次机制，不新增一套请求框架。
- 加载B时清楚显示“正在加载B”，不能把A的内容挂在B的标题下。相同资源刷新可保留上次结果并标明正在刷新，但旧预览不能用于确认新参数任务。
- 查询条件变化只影响展示；预览、草稿和任务提交各自独立。只有当前条件对应的最新成功预览才可用于提交，最终仍由服务器检查权限、参数和规则/池修订。
- 写请求发出后暂时锁定相关提交操作。服务器明确拒绝时恢复可修正状态；结果未知时说明“尚未确认是否成功”，先查询实际对象或本人任务。重试读取可以直接执行，不能自动重复创建、复制、删除或模拟提交。
- “已保存”“任务已接受”“任务完成”是三个不同结果，按服务端实际响应分别显示。接受任务后可以离开页面；动画或页面关闭不表示任务取消，停止任务必须调用明确的取消操作。

## 5. 名称、数字、空值及说明文案

| 数据含义 | 统一展示 |
| --- | --- |
| 确实为零 | 显示0或0%，不能当作缺失 |
| 没有配置 | 显示“未配置角色/奖励”等具体内容及可用设置入口 |
| 当前统计不适用 | 显示“不适用”及必要原因，例如直接赠送没有抽取概率 |
| 没有匹配记录 | 显示“当前筛选无记录”，提供调整或清除筛选入口 |
| 尚未读取/读取失败 | 显示相应状态，失败提供重试；不冒充0或空列表 |
| 数据缺失或不受支持 | 明确“数据缺失/当前版本不支持”，不能使用默认值伪装成正常结果 |

- 业务判断使用稳定ID、明确类型及能力，不依赖“四星/五星/六星”等名称。当前池可以覆盖显示名；历史按冻结快照显示，改名不改变统计身份或重算历史。
- 名称优先展示，重名时补充所有者、公共/私有属性等区别；仍不能区分时提供短ID及完整详情。长名称允许换行或展开，不能截断到无法识别；完整值不只依赖鼠标悬停获取。
- 抽数、轮数、数量等整数保持精确，超出JavaScript安全范围时沿用十进制字符串/BigInt。百分比与百分点分清；小正概率不能只显示0%，可使用更多有效位或科学记数法；图形近似应明确说明并保留精确数值表。
- 时间按用户可理解的日期时间格式显示，涉及跨环境对照时注明时区；耗时标明单位。每轮、全部轮次、含历史累计、本次新增四种范围在标签中明确，不能让用户猜分母和统计口径。
- 帮助文字分成一句用途、字段单位/约束、可展开的完整例子。说明必须对应当前生效状态；内部状态、机制代码统一映射为中文，ID、修订和技术诊断放在次级详情。

## 6. 新增字段和机制的扩展约定

新增字段至少定义以下内容，作为开发及审查清单，使用普通类型、组件参数或说明即可，无需引入运行时表单引擎：

| 项目 | 必须说明 |
| --- | --- |
| 身份与含义 | 稳定字段/机制ID、用户名称、用途、单位及统计范围 |
| 适用条件 | 所需权限、父机制、模式、前置条件及互斥关系 |
| 初始值 | 新建默认值、关闭后保留方式、重新启用行为 |
| 编辑与显示 | 编辑输入、只读表现、自动计算依据及格式化方式 |
| 校验 | 类型/范围、字段错误、跨字段约束及隐藏后错误入口 |
| 保存与历史 | 草稿到API映射、保存时点、快照展示及导入导出要求 |

新增稀有度按规则定义及稳定ID渲染，不能添加固定4/5/6星判断。新增机制明确它是否产生抽取、奖励、赠送事件及影响哪些状态，再决定结果页和明细字段；不能仅凭“看起来像赠送”复用错误的展示口径。

未知机制或前后端版本不匹配时，保留可安全展示的已知信息并提示“不支持的机制/版本”。无法完整理解的配置不能在编辑保存时丢弃未知字段或按默认值覆盖，也不能继续提交相关模拟；提供刷新完整版本、只读原始详情或现有导出入口，权限与数据校验保持有效。本约定不增加旧格式兼容或迁移框架。

## 7. 动画、布局与可访问性

未来实现抽卡动画时需遵守：结果先由计算核心确定并按任务状态保存，动画只消费结果。跳过、加速、关闭或重播不重新采样、不消费核心随机数、不重复提交任务、不增加历史或奖励。重播明显标为重播；停止播放与停止后台模拟使用不同操作。未完成/未保存的任务不能因为播放结束而标为完成。

动画不能阻塞查看文字结果，保留静态展示和减少动态效果选项，优先尊重浏览器系统偏好。长列表和大量Trace仍分页，不能为了动画一次加载全部历史事件。

布局以桌面浏览器、中文和鼠标/键盘为主，同时适应窄屏及缩放。控件展开与收起保持可见焦点，错误定位能展开适用区域；状态不能只靠颜色表达。名称、帮助文字和按钮允许必要换行；大表格局部滚动，主操作和错误提示不被整页横向溢出挤走。图表继续保持自适应尺寸和可读取数值。

## 8. 共用实现与范围控制

共享机制展开区、字段错误/只读值、中文状态及数值格式化等实际重复部分；页面使用同一套显示条件与草稿处理约定。后端校验独立保留，前端显示规则不能改变权限、抽样规则或数据契约。

具体实施范围由对应设计和计划规定。复制界面明确准备与保存阶段，优先复用已有接口；自动保存、版本合并、新机制、多语言、动画及插件系统需要各自明确需求，不能因本规范提到扩展约定就自动新增功能。

## 9. 共用验收清单

以下是场景集合，不是每次修改的必跑列表。按实际改动选择相关场景，同一功能的相关修改完成后集中验证，不穷举所有开关组合。仅改帮助文字通常只核对文字及其适用状态，不重跑权限、下载、取消等无关流程；只有布局变化才追加相关窗口尺寸、缩放和键盘检查。

- 开启→填写→关闭→重新开启，以及关闭保存→重载→重新开启：合法值保留，生效说明正确。
- 无效输入后收起、模式切换、父子依赖变化：问题入口可见，不丢弃输入，不让隐藏错误无声阻止保存。
- 新建/编辑/查看/复制及普通用户/管理员：写入时点、权限、署名和对象身份一致。
- 离开未保存草稿、保存失败、版本冲突、权限撤销：按权限保留或清除，明确去留，不覆盖他人变更。
- A请求晚于B返回：当前内容仍对应B；账号切换后旧响应不能恢复私有数据。
- 预览后改参数、提交结果不明：预览失效，不重复创建任务。
- 零值、未配置、不适用、缺失、无匹配、读取失败：显示含义明确。
- 长名称、重名、极小概率、大整数：能识别对象且不丢精度。
- 中文阶段、明细筛选、历史快照：统计口径和后台实际状态一致。
- 桌面、约390px窄屏、200%缩放、键盘操作：焦点可见、控件可操作、无整页横向溢出；必要表格局部滚动。
- 动画功能实际加入后再验证跳过/重播/关闭均不改变结果，不提前创建播放功能或测试。

优先复用已有用例验证行为与请求效果，不为每句帮助文字单独写测试。需要浏览器验收时确认加载了实际构建；相关检查通过且没有新疑点后停止，不再重复用其他工具验证同一现象。验证范围与停止条件遵守[开发与验证规范](development.md)。
