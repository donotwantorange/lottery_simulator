# 权限与资源规范

来源：[账号与资源设计](../changes/2026-09-24-user-pool-experiment-design.md)、[独立规则设计](../changes/2026-09-30-independent-rules-rarities-design.md)。这里集中维护权限约束，密码长度等具体设置仍按当前账号契约。

范围：谁可访问、修改或删除资源，以本文件为主要维护位置；权限对应的页面表现见[界面规范](ui-interaction.md)，任务保存及取消一致性见[架构与数据规范](architecture-data.md)，服务器文件和卷的删除操作见[部署规范](deployment-safety.md)。

## 账号与数据隔离

- 匿名用户不能访问业务数据，开发模式也不提供匿名管理员权限。
- 普通用户管理自己的实验配置、任务与历史；管理员可按既有功能管理全部。管理员免除业务数量限额，不免除类型、权限关联、存储可表示范围及资源保护。
- 每个读取、修改、取消、删除、下载及重存入口都由服务端检查当前身份和资源权限；前端隐藏按钮不构成授权。
- 用户名、角色、启用状态或密码等安全属性变化撤销旧会话；请求使用当前账号状态及授权版本，不能信任过期对象或客户端角色字段。
- 已接受任务按冻结的接受条件执行；退出登录或禁用账号不等于取消任务。账号删除走独立的删除门禁及任务清理流程。

## 公共与私有资源

- 公共规则和池为公共资源，由管理员管理，不绑定某个管理员作为个人所有者。
- 私有资源归创建者；公开仅允许其他登录用户查看、使用、复制，不授予编辑权；创建者和管理员可以维护。
- 公共池只绑定公共规则；公开私有池绑定公共或公开私有规则；隐藏私有池绑定其所有者有权使用的规则。
- 管理员代管他人资源时，关联能力按实际所有者校验，不能把管理员权限转嫁给普通用户。
- 被引用规则不能直接删除；修改可见性、复制、导入和切换引用均重新校验。已引用规则的结构调整通过复制新规则及明确映射完成。

## 复制、导入与署名

- 类型转换通过复制创建新ID，不修改源对象或原引用；保留最初作者署名，不累积中间复制者。
- 公共资源及原作者署名不因删除某个账号而自动转移或改写。
- 导入文件不能授予数据库所有权或更高权限。按当前导入契约新建资源，再校验引用。
- 引用按ID优先解析，缺失时才做名称候选确认；无权访问的精确ID不能通过名称回退泄露或替换。候选选择仍需服务端再次检查。

## 删除、下载与私密信息

- 删除前明确影响范围；被他人引用的私有规则需先解决引用，不能级联删除他人资源或自动转移所有权。
- 删除中账号拒绝新业务绑定，使用持久清单处理可重试清理；未知任务状态不能被当作可安全删除。
- 下载在生成与传输过程中检查会话和资源权限，保留CSRF及撤权处理；不把完整大文件加载到前端内存来代替受控流式导出。
- 不向其他用户暴露隐藏资源身份、任务路径、会话、密码散列或备份材料。日志、截图、变更记录和静态前端不包含密钥。
