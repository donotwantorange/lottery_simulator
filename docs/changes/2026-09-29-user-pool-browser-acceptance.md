日期：2026-09-29。工作树：`.worktrees/user-pool-experiment`。浏览器：Codex内置浏览器；前端127.0.0.1:5173、API127.0.0.1:8000。数据独立置于`/tmp/lottery-task14-browser.7DusRj`，未连接真实历史库。

## 已观察的行为

- 临时库migrate与交互init_admin成功；管理员和普通测试账号均经真实登录表单成功进入页面。退出时按钮禁用，随后可以换账号。
- 管理员可见五个导航入口；普通账号没有管理入口。普通账号历史列表初始为0，管理员历史ID深链接显示“历史不存在或不可访问”，未显示他人结果。
- 普通账号查看公共池只有只读控件；复制成隐藏私有池后可编辑，池ID重新分配，原作者署名保留。
- 管理员40主抽×2轮开启Trace，实际完成并保存100条（80主抽+20赠送）；普通账号10主抽×1轮关闭Trace完成，历史只出现本人记录。
- 登录后刷新历史深链接保持会话并显示历史快照。当前任务结果的池名称缺失已修复，重启后实际显示“默认角色池”。
- 分类统计加载本地Vega图，星级模拟/理论并排显示。按抽次星级全空选显示提示；单选五星和赠送来源可查询，不重新提交模拟。
- 逐抽表选择全部轮次和赠送，显示20条；完整列显示0～1概率、来源池及主池状态，赠送期间主池累计保持30。
- 原生下载按钮发送带CSRF的表单POST；服务日志实际响应200（全部第一轮47961字节，双轮赠送筛选23761字节）。组件不使用整份fetch/Blob。内置浏览器未向自动化暴露新标签下载事件，因此不以下载事件缺失判定失败，也不声称核对了操作系统保存位置；附件内容完整性另由后端流式测试检查。
- 管理员页实际列出两个账号及跨用户任务，未显示磁盘路径。
- 临时10000主抽×10轮任务在理论阶段点击停止，先显示“已请求停止”，随后显示`cancelled`；主抽完成不等同于整任务完成。

## 边界

这些观察证明本地页面与API链路，不代替并发、撤权、磁盘故障和大文件后端测试。未验真实公网HTTPS、反向代理运行、生产Docker/Caddy或真实数据切换。浏览器改密/账号永久删除未代替用户执行，相关业务边界由临时环境自动测试验证。
