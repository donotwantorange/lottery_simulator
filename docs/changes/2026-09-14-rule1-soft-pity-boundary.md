# 规则 1 软保底边界调整

日期：2026-09-14  
规则版本：`1.1` → `1.2`

## 变更内容

- 第 1–65 抽的主池六星概率统一为 0.8%。
- 第 66 抽开始软保底，概率为 5.8%，之后每抽增加 5 个百分点。
- 第 79 抽概率由 75.8% 调整为 70.8%。
- 第 80 抽仍为 100% 硬保底。
- 六星后的保底重置逻辑及首次 30 抽赠送子规则均不变。
- 规则版本提升至 `1.2`，使新结果能与历史 `1.1` 结果区分。

公式：

```text
p(n) = 0.008                         1 <= n <= 65
p(n) = 0.008 + 0.05 * (n - 65)      66 <= n <= 79
p(n) = 1.0                           n = 80
```

## 理论结果变化

- 完整周期平均间隔：`53.89927355371174` 抽。
- 长期综合六星率：`1.855312574859621%`。
- 标准差：`23.036219232912913` 抽。
- 中位数：第 67 抽；众数：第 69 抽。
- 90% / 95% / 99% 分位数：第 73 / 74 / 76 抽。
- 恰好由第 80 抽硬保底结束周期的概率：`0.029933681818068074%`。
- 从零保底开始进行 80 次主抽的六星期望：`1.2533176900565965`。
