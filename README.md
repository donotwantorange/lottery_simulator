# 抽奖模拟器

抽奖模拟与理论分析工具。网页使用 React＋Django，提供独立规则、角色池、实验配置、历史与 Trace；Python CLI 可读取 JSON 配置独立分析和模拟，不写网页历史。

## 数据与版本

当前代码默认使用 `data/history_v6.sqlite3`、`data/jobs_v6/` 和 `data/exports_v6/`。v5 数据不会自动升级或被覆盖。保留旧账号时，先将账号和登录防护从明确指定的只读 v5 数据库导入空 v6 库；旧池、实验、历史和会话不导入。操作步骤见[部署指南](docs/deployment.md#v5账号保留与v6切换)。

规则决定抽取概率、保底与赠送；池绑定一条规则并保存角色、权重、UP分组和奖励；实验引用池并保存运行参数。结果冻结规则、池和参数快照。Trace 关闭时只保留汇总，开启时保存抽取与直接赠送事件。具体统计口径见[网页指南](docs/dashboard-guide.md)。

服务器当前已通过用户确认的手动指令部署。新版界面与接口已完成本机隔离验收；自动安装和新版服务器部署尚未实机验收。旧版手动部署成功不能证明新版服务器功能或自动安装通过。当前验证边界见[部署验证状态](docs/deployment.md#验证状态)。
